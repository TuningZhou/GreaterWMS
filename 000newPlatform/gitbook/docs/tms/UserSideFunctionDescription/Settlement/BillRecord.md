# 账单记录

【功能概述】账单费用查询，账单明细导出。

![](../../../.gitbook/assets/images/7166d63edac4-1724312772051-e2874d62-f6ef-4b94-bda2-6702508df516.png)

客户无法对账单费用进行任何编辑、修改等操作，账单由管理端创建，已生成的账单通过操作可以导出发票、账单明细等动作。  

![](../../../.gitbook/assets/images/655a97912501-1724312796313-69c7eda5-8813-4233-8dd1-54d3db86529d.png)
