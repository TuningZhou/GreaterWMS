# API授权说明

【**功能概述**】第三方ERP授权，客户可以通过ERP推送订单到系统中来进行发货处理，目前系统对接的ERP有**店小秘**、**全球交易助手**和**芒果店长**，客户可以通过API授权来进行ERP的对接.  
点击**新建**，选择**授权已有APP**

![](../../../../.gitbook/assets/images/e9587d7fd9e7-1646361067814-5c3c4ae7-8b0e-4510-a0ab-8438d1839d07.png)

  
店小秘 App Id：**lXXSTYQT**  
芒果店长 App Id：**eF4YAoRH**  
全球交易助手 App Id：**9AZaHR24**  
在**App Id**处录入上方需对接的ERP App Id，点击确定  

![](../../../../.gitbook/assets/images/c334883637cc-1646361385227-c9665a87-593c-436c-9c64-20356ad1a8dd.png)

  
系统会自动生成ERP对接所需的**App Key**和**App Secret**,点击可查看完整的API Token  

![](../../../../.gitbook/assets/images/9745570e11a2-1646361913685-b0726c30-9552-4c6f-9c8f-e942d76b5d44.png)

  
到ERP物流商处搜索**大迈未来**，用系统中生成的**App Key**和**App Secret**对账号进行授权，货代名称、别名自定义编辑.  

![](../../../../.gitbook/assets/images/5b17ba091dc5-1646362277535-9a0aefa6-9759-4541-888f-b7bf34c19875.png)

  
点击**保存**ERP对接完成，最后对物流商提供的渠道进行启用就可以将ERP的订单推送到系统中了  

![](../../../../.gitbook/assets/images/d176a9584b8e-1646362593597-47901f1e-f5d4-4c0e-9a62-9392e45725eb.jpeg)
