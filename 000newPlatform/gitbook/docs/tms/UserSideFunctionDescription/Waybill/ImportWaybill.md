# 导入运单

【**功能概述**】运单批量导入系统  
系统支持3种不同类型的运单导入，客户可下载系统默认的导入模板进行导入，也可以自定义模板字段后下载导入

![](../../../.gitbook/assets/images/6fb73e9149f9-1723629517291-b86432ac-b695-40c6-9d3c-92025b7796ae.png)

  
在下载的模板中逐项录入运单信息后保存  

![](../../../.gitbook/assets/images/58c6365206c4-1723629902402-0e08bee9-abf2-4f65-8dbf-da4e1616793a.png)

  
点击上传并保存编辑好的Excel表格  

![](../../../.gitbook/assets/images/414263e7cb3f-1723629819413-7de8a5d3-f1b2-4542-835c-15db864ac872.png)

  
保存成功后可到运单列表草稿栏中再次编辑或者进行确定提交  

![](../../../.gitbook/assets/images/0d9537f74fd6-1723629891203-264223b1-b443-4cde-97fe-13afd94a812a.png)

  
如果模板上传失败，系统会弹出导入失败信息，点击下载，下载文档查看错误信息。  

![](../../../.gitbook/assets/images/2a49be3d9062-1723629961618-e163f203-008d-4bd4-8867-ae49a54ae5a3.png)

  
下载的文档在最右端查看错误信息，根据提示内容更改有错误的地方后重新上传  

![](../../../.gitbook/assets/images/7bac0190cf6d-1723630005982-2853e99b-d959-4a4f-b1c6-157c2c97dc7b.png)

  
**自定义导入模板**  

![](../../../.gitbook/assets/images/936d54b79f0b-1723685122410-28e08d40-e962-4209-8274-69fd7c4cc24a.png)

  
点击新建  

![](../../../.gitbook/assets/images/c30439684b25-1723685161266-34771731-34c4-48dc-9f6d-a9896d28e5c3.png)

  
录入模板名称，选中下方所需要的的字段移动到右边进行保存  

![](../../../.gitbook/assets/images/dcdfbe57824a-1646303082457-26c6acbf-e5f7-4ab1-820d-83f67f230bb9.png)

  
可以设置该模板为默认下载模板  

![](../../../.gitbook/assets/images/9ca357a692fd-1646303126623-7d367680-229d-4902-a1e5-0fee4c01d08b.png)

  
模板创建成功后选择创建好的导入模板进行下载就可以了  

![](../../../.gitbook/assets/images/652ee2c86b4e-1723685208788-49f23870-a9cd-48c4-b607-3e873b964d3b.png)
