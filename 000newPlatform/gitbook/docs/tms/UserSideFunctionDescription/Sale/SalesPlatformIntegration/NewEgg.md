# NewEgg

登陆NewEgg后台，点击【**数据接口设置**】

![](../../../../.gitbook/assets/images/8c87c6b9b894-1692239471408-9ab3bd12-1446-4718-b05d-35c300fb4cc7.png)

  
在【**API设置**】获取**商家编号**、**API秘钥**、**密钥**信息.  

![](../../../../.gitbook/assets/images/70cd7ad3b276-1692239774876-c6bc7f15-b930-460a-b94f-3cc67dea1aa2.png)

登陆系统客户端**【销售】—【平台账号】新建**  
将NewEgg后台获取的API信息复制到指定位置保存.  

![](../../../../.gitbook/assets/images/51ef2e266c8d-1692240564556-5ebcd471-b113-45f3-a63c-bb466d98b7ca.png)

点击自动同步设置订单下载时间.  

![](../../../../.gitbook/assets/images/db2b613567c5-1692240372147-de145b2a-886f-4d48-80fe-00b6c1af692e.png)
