# Shopify

登陆 Shopify 账号进入设置界面

![](../../../../.gitbook/assets/images/755925224ce0-1679552507556-a6265a64-1491-4fec-a6ec-8d2527a15376.png)

  
点击**应用和销售渠道**  

![](../../../../.gitbook/assets/images/b12acfee4c48-1679552605273-f215822c-d900-4763-bba8-facb9209871b.png)

  
点击**开发应用**  

![](../../../../.gitbook/assets/images/aa218a191eb8-1679552769470-eda86b94-41cc-4df9-96a0-974e211e9a11.png)

  
在应用开发中**创建应用**  

![](../../../../.gitbook/assets/images/224e2b2a4cb7-1679552928048-37fddfb2-5c53-4910-b31e-27543946a32d.png)

  
**应用名称**自定义  
**应用开发者**：maida([dev@dmxsmart.com](mailto:dev@dmxsmart.com))  
注意事项：店铺主账号默认是应用开发者，如遇到应用开发者无法输入的情况，可以随便选择一个已有的应用开发者.  

![](../../../../.gitbook/assets/images/b5243490de04-1679553552219-f183fa17-e2e7-48d8-aba6-c2b767d76485.png)

  
应用创建成功后，点击**配置后台API范围**  

![](../../../../.gitbook/assets/images/4238b3bcb290-1679553624962-ddf937a0-0662-46e1-a4be-8ae76149b2f8.png)

  
将以下参数全部勾选上并保存  

![](../../../../.gitbook/assets/images/1908c5df44d7-1679553988644-a4991370-36c8-416f-88fd-fafdef3c0ae2.png)

  

![](../../../../.gitbook/assets/images/d8fe790c3607-1679554006536-831c9886-9314-47a7-b691-aa51a84037b4.png)

  

![](../../../../.gitbook/assets/images/494aa452e798-1679554137551-1ab6f2b7-f7d4-4394-8d92-89f38e5bef90.png)

  

![](../../../../.gitbook/assets/images/648c96a24718-1679554187150-aad0079f-9cc2-4ef7-9ed3-8ba75919f6de.png)

  

![](../../../../.gitbook/assets/images/4e7cb5822a83-1679554213616-27ff1906-9a53-4af3-ad8d-4636b4ffc160.png)

  

![](../../../../.gitbook/assets/images/488ff65cc50c-1679554564258-dc522f36-f0a0-4f2c-932f-2fe4c841cd4c.png)

  
在应用开发中选择配置好的应用，点击**安装应用**  

![](../../../../.gitbook/assets/images/5f74dddc6bba-1679554785775-08f34b84-15ea-4c03-8b39-4985c4088ea4.png)

  

![](../../../../.gitbook/assets/images/35a8ffc1589a-1679554868933-620690c9-3b4e-444e-b5da-7229d12140dc.png)

  

![](../../../../.gitbook/assets/images/037db6b7382d-1679554992471-596c253c-72aa-458d-9b2d-312450dfb49e.png)

  
完成安装后会生成**后台API访问令牌**（API Token）  

![](../../../../.gitbook/assets/images/55a65f93d97b-1679555097935-03e0ee33-2a00-413a-b57a-8e1de924c3ec.png)

进去系统**销售**---**平台账号**---**新建**  
**账户类型**选择Shopify  
将API令牌（Token）复制粘贴到系统的 accessToken 处

![](../../../../.gitbook/assets/images/d5f4f0d29407-1679555391930-036b7b94-2c92-4204-82d7-7ed9cfabcbf0.png)

**销售账号**：自定义  
 **StoreName**：填入 .myshopify.com 前面的文字  
（例如店铺网站是damai123.myshopify.com那么StoreName 就填damai123）  
录入后保存，完成Shopify账号对接.  
通过**自动同步**和**拉取订单**功能将Shopify订单同步到系统提交出库.
