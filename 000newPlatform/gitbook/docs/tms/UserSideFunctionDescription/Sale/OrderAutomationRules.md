# 订单自动规则

【**功能概述**】订单发货规则设置，平台订单下载时给符合条件的订单自动分配发货仓、运送方式来提交出库，不用每个订单手动提交出库。

![](../../../.gitbook/assets/images/6fe16bbfaf84-1724317315251-76101f9c-5fa9-4d47-aba1-2da833a687c4.png)

  
**规则名称**自定义  
**执行条件**选择所有同步的订单执行发货规格还是只有满足条件的订单执行发货规则  
设置规则条件以及需要执行的动作  

![](../../../.gitbook/assets/images/b966075a5ecd-1679900374700-6d20a8d8-8165-4841-b9d2-76d1961cf22a.png)

可以同时创建多个订单规则，系统将会按照从上到下的优先级逐个运行，通过拖拽规则排序调整优先级顺序。  

![](../../../.gitbook/assets/images/3e252f6f65ee-1679901007068-989dccad-f8fd-4f2c-a1b2-39510f256c9d.png)
