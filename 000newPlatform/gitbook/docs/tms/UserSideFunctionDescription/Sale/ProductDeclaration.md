# 产品申报

【**功能概述**】需要录入产品申报信息的运单，可以提前将产品的申报信息录入到系统中，在订单提交时选择填充到报关信息中  
点击新建，录入申报信息后确定保存

![](../../../.gitbook/assets/images/492e56049c64-1724308688236-2a6cb9ce-5b27-44ba-ab10-9be56699c3d2.png)

  
通过批量导入的方式导入产品申报信息，点击导入，下载导入模板  

![](../../../.gitbook/assets/images/2328e3236d2c-1724310058998-26d05010-238e-4c9c-a36f-31ae5389c365.png)

  
在模板中录入产品申报的各项信息后点击上传。
