# 平台订单

【**功能概述**】系统绑定销售平台账号后，可以通过手动拉取订单的方式将销售平台订单同步到系统中来  
点击**拉取订单**，选择销售平台账号，系统会将销售平台订单拉取到系统中

![](../../../.gitbook/assets/images/f2a275d4c6af-1724291992087-75cb79a3-6f98-4695-b61b-71779832d795.png)

  
订单拉取成功后，选择订单，点击**生成运单**来生成发货渠道的跟踪号码  

![](../../../.gitbook/assets/images/2d10c30709aa-1724316697560-edd79bb6-969f-40e3-bde5-b0a215756ca0.png)

  
生成跟踪号的订单会转入**已生成订单**栏，选中订单点击**回传跟踪号码**，订单跟踪号会同步到销售平台中  

![](../../../.gitbook/assets/images/5053e54a6267-1724316743466-c1cef455-e890-40c4-9fe5-3af5a766f3d1.png)

  
在待处理列表中，我们还可以通过操作来选择货物的发货仓库和运送方式  

![](../../../.gitbook/assets/images/41a51de2eecc-1724316786153-5d174402-fa5b-42f7-90c9-8c624866bc1f.png)

  
SKU映射和报关信息填充都可以通过操作来设置提前录好的产品报关信息以及SKU映射关系。
