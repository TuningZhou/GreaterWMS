# 其它费用

【**功能概述**】统计公司运营中出现的一些其它开支费用，管理公司的每一笔收支明细，帮助公司财务进行成本核算。

![](../../../.gitbook/assets/images/f29c172f3a44-1722998651701-fb819c22-b794-43b6-9562-a37e28948749.png)

  
选择发生交易的银行账户，交易类型可选择是**支出**或者**收入**，会计科目通过后方**设置**图标新增类型，录入金额后确定保存。  

![](../../../.gitbook/assets/images/877a4258bd80-1662454853202-fa23fc58-60e4-4b58-ae6e-59d0c639049e.png)

  
可在银行账户流水中查看
