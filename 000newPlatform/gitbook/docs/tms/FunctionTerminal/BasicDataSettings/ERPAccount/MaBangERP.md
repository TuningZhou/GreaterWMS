# 马帮ERP

注册马帮镖局账号，注册地址链接：[镖局物流-跨境物流开放平台](https://www.i8956.com/)  
账号注册后需要联系马帮开通物流API权限，权限费用租户自己支付，可联系马帮客服付费开通.  
登陆镖局账号，【系统管理】-【基础信息维护】-【API账号】

![](../../../../.gitbook/assets/images/aa752da53294-1680511835817-42dd4611-5695-4eab-b9bd-4932e2e4965c.png)

将镖局 API账号ID 和 API秘钥 复制到系统 apiAccountId 、 apiKey 处  

![](../../../../.gitbook/assets/images/a70682362b91-1680511840503-a8c8008e-9d5f-42d9-bd77-98ef49f32688.png)

在镖局创建产品（运送渠道）  
【产品管理】-【我的产品】-【新增自定义产品】  

![](../../../../.gitbook/assets/images/849811c4bdf8-1680512133003-7e65514a-cd44-47a8-8c64-0a3530a9dfcb.png)

根据渠道要求填写产品基本信息、发货说明、运费设置等  
物流API类型选择马帮开通的API权限，地址标签、运单号、发票等选择使用接口返回  
注意：**物流商自定义字段**必须输入系统对应的**运送渠道编码**  

![](../../../../.gitbook/assets/images/b3e202f3b40c-1680512227857-ec494324-734c-4093-a2ce-ab84e058af0f.png)

![](../../../../.gitbook/assets/images/630f4b7570ff-1680512580519-bd91b134-7789-4744-a5fb-e0bcdb12955e.png)

  
保存后还需要对产品上线测试，只有测试通过的产品才可以启用  

![](../../../../.gitbook/assets/images/888a2a6656ed-1680513016452-7b6c60f6-8d43-410a-8f40-be181ef966cf.png)

产品启用后，客户在马帮ERP搜索物流商名称进行授权，选择镖局启用的产品下单发货.
