# 1.创建仓库

【**功能概述】**仓库初始化设置，在系统创建仓库的基本信息，包括仓库编码、名称、仓库所在国家以及仓库地址等信息。  
【**功能入口**】（**仓库**—**仓库管理**—**新建**）

![](../../../.gitbook/assets/images/cb56009deeb8-1662601857342-6256de63-733d-469c-b087-c9fcf00da718.png)

仓库编码可由字母和数字组成，选择仓库所在国家时区，录入地址等信息后**确定**保存。**“*”**号为必填项

![](../../../.gitbook/assets/images/e2c284927972-1662601892731-9489eb45-8a4b-4e4b-b162-3937044dd4b4.png)

保存的仓库信息将展示在列表中，可以对仓库状态进行更改以及修改仓库信息。

![](../../../.gitbook/assets/images/b00e1af75730-1638779508335-59df6fd8-e3f3-4566-8a16-0ad2bb4312bc.png)
