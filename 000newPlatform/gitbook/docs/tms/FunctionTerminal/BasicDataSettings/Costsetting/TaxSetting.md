# 税金设置

【**功能概述**】针对发往日本需要收取税金的产品，可在系统设置税金方案

## 汇率管理

【**功能入口**】（**渠道**—**汇率管理**）  
点击分类维护创建汇率方案名称

![](../../../../.gitbook/assets/images/623a8a022de2-1724916660474-d5ac3ea7-1548-418f-ae37-6a46060457df.png)

  

![](../../../../.gitbook/assets/images/3e20b420b218-1724916639237-d12c7a89-1e14-4bf7-af46-e517973e04b0.png)

  
点击新建创建汇率方案  

![](../../../../.gitbook/assets/images/c14e1d323091-1724055036396-ae96596b-b9d0-482c-850b-1cb502439eb3.png)

  
输入币种和汇率，选择有效时间  

![](../../../../.gitbook/assets/images/749f36bdedb7-1724055112664-95bdba0d-b104-4902-89ac-cbe09868f10f.png)

  
确定保存后可在列表对其进行编辑和删除  

![](../../../../.gitbook/assets/images/71e9b2f4f278-1724055193020-32a042b2-eee6-4c9f-a13d-8a3fc91a4e9c.png)

## 税金计费

【**功能入口**】（**渠道**—**税金计费**—**税金方案**）  
点击新建创建税金方案，在基本信息中输入方案名称，选择结算币种和创建好的汇率方案等

![](../../../../.gitbook/assets/images/fde41a3622fe-1724055343299-84132823-a945-45c7-9cc8-551abd4d9f34.png)

  
在税金列表处添加税率  

![](../../../../.gitbook/assets/images/f8e298335736-1724055562491-aa111cdc-6d0a-4b43-8bfc-1e52bcf7d150.png)

  
在基本信息中选择需要计算的税率  

![](../../../../.gitbook/assets/images/c6798cbf5289-1724055499134-3b712ed1-0dd7-4ae7-88d5-4bfade890b63.png)

  
在关税税率处添加税率，设置完毕后点击确定保存  

![](../../../../.gitbook/assets/images/28c5979cd84d-1724056192355-9d975448-a595-4ad4-a517-c712cd222702.png)

  
设定好的税金方案将展示在列表，可点击对其编辑和删除  

![](../../../../.gitbook/assets/images/944b32ffc71f-1724056411130-b4b52e02-9c40-484f-bf55-4b54031356e6.png)

## 税金计划

【**功能入口**】（**渠道**—**税金计费**—**税金计划**）  
为税金方案绑定价格，也可根据不同的客户设置不同的税金方案。  
点击新建税金计划

![](../../../../.gitbook/assets/images/f69a5f61dcf4-1724056610247-6857a1b3-1385-483d-92f3-c840fa9a7c80.png)

  
选择仓库、运送方式和税金方案  

![](../../../../.gitbook/assets/images/1336c3be212c-1724056710976-22a4fd97-f287-4a22-bd04-3a7edc9c3d18.png)

  
选择价格类型为客户特殊价格，可为不同客户设置不同税金计费  

![](../../../../.gitbook/assets/images/f9c811475b26-1724056670169-69f9f540-373a-4233-9961-3a4e827b346d.png)

  
可在列表中查看到已保存的税金计划，点击对其进行编辑和删除  

![](../../../../.gitbook/assets/images/1f39c788900d-1724056863219-a7a6ea0e-2203-411e-a579-a94d2bd05fd1.png)
