# 系统设置

## 角色管理

在 **OMS ＞设置 ＞角色管理**中新建角色，选择操作仓库，在**菜单权限**中为该角色分配系统的操作权限。

![](../../.gitbook/assets/images/0d52cc6bbdf7-1721014044697-49df456e-3727-43ad-bb20-38ea4fb7cbdf.png)

  

![](../../.gitbook/assets/images/88d836de7731-1721014059063-b2a9d142-b123-4d80-8ba3-131afa69a78d.png)

## 用户管理

角色权限配置完成后，在**OMS ＞设置 ＞用户管理**中给不同的角色开通登陆账号，点击**新建**，设置登陆账号和密码，选择角色，不同的角色所分配的操作权限不同，也可以为该账号同时添加多个角色。*号为必填项。

![](../../.gitbook/assets/images/d44e5b7923f0-1721014067544-0b268715-0e8e-41fd-8572-3cba1843e7fd.png)

## 常用地址

在**OMS ＞设置 ＞常用地址**中编辑常用收件人地址和发货地址。   
点击新建，录入地址详细信息后确定保存，收件人地址和发件人地址创建好后可以在创建打单时选择使用。

![](../../.gitbook/assets/images/afe0afd8c0d3-1721014099921-d4050221-7c49-47c3-96ee-63bae64ad50b.png)
