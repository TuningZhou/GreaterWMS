# 支付宝

## 1.注册支付宝企业账户

注册链接：[注册 - 支付宝](https://memberprod.alipay.com/account/reg/index.htm)

![](../../../../.gitbook/assets/images/15a444fcf54b-1681705381531-1fe96106-3b75-44c8-8be0-b4a2040fdde7.png)

准备相关材料完成支付宝企业账户的注册及认证  

![](../../../../.gitbook/assets/images/ece25467e3e2-1681705563854-7b474bba-c296-480d-969b-6de0d23bad73.png)

## 2.开通支付宝当面付

[支付宝商家中心-国内领先的第三方支付和金融服务平台](https://b.alipay.com/signing/productDetailV2.htm?productId=I1011000290000001003)  
根据官方文档流程签约支付宝当面付

## 3.创建应用

登陆支付宝企业账户，进入控制台创建**网页&移动应用**

![](../../../../.gitbook/assets/images/31c0fbf02d6c-1681705979450-e8cb7d31-82d9-440c-9bf4-15d2e0120886.jpeg)

  
创建完成后为应用配置加密的秘钥  
操作指南：[小程序文档 - 支付宝文档中心](https://opendocs.alipay.com/common/02kdnc)  

![](../../../../.gitbook/assets/images/38d7c4f82832-1681706134099-90169743-d65d-46e5-8fe1-52b62f95d71a.jpeg)

  
直接用支付宝开放平台开发助手生成秘钥(需要下载)  
公钥分为支付宝公钥和应用公钥  

![](../../../../.gitbook/assets/images/e315e5efe230-1681707462749-da774aa0-7d0f-491e-90ff-7f0bacfc5c65.jpeg)

  
注意：应用必须审核通过后才能使用，否则即使配置好也没办法使用.  

![](../../../../.gitbook/assets/images/03ac7bfd848a-1681707683500-0a24cda1-0ec4-4eaa-a3b5-06021dc75a1e.jpeg)
