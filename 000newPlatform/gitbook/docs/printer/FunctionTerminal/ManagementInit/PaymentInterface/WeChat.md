# 微信

## 1.注册微信支付商户号

[微信支付 - 中国领先的第三方支付平台 ｜ 微信支付提供安全快捷的支付方式](https://pay.weixin.qq.com/index.php/core/home/login?return_url=%2F)  
注册审核流程参考微信官方文档：[微信支付商户接入指引](https://kf.qq.com/faq/210423UrIRB7210423by6fQn.html)

![](../../../../.gitbook/assets/images/f9dcfa1c58a4-1681701052424-859bfa21-3501-4e6f-a2e4-8d8138a83847.jpeg)

![](../../../../.gitbook/assets/images/57139f5b0e22-1681701080328-7ef16e46-83e1-45a4-a8ea-2456ed15227f.jpeg)

![](../../../../.gitbook/assets/images/f713d24270d3-1681701124074-2549ac5b-90ed-45db-bf7b-4058fe0b98e8.jpeg)

  
按照接入教程指引完成提交资料、账户验证、签署协议、绑定场景.  
注意：填写商户信息时**经营场景**选择PC网站，网站授权函联系我司客户经理提供.  

![](../../../../.gitbook/assets/images/5f2ab84c0c1e-1681701222267-53e27294-dde6-401a-80fc-706b68e29f6f.jpeg)

## 2.**登陆微信支付商户平台获取商户API证书**

API证书获取指引：[什么是APIv2密钥？如何设置或修改？](https://kf.qq.com/faq/180830UVRZR7180830Ij6ZZz.html)

![](../../../../.gitbook/assets/images/8174e9fa9523-1681701398866-e6f7687b-d5eb-4c49-9e23-92f85365cd58.jpeg)

  
（请务必妥善保管证书及私钥，因为私钥文件只能通过证书工具导出，若私钥丢失，则无法找回，只能作废后重新申请。）

## 4. 申请开发者资质认证

流程指引：[open认证流程](https://kf.qq.com/faq/170824URbmau170824r2uY7j.html)

## 5.AppID 账号管理关联 AppID

![](../../../../.gitbook/assets/images/6fcfbf4e10e0-1681702218425-c75663e5-0cbe-4b32-a94b-19818d373e17.jpeg)

  
最后将AppID、APIv2秘钥和微信支付商户号设置到系统中.  

![](../../../../.gitbook/assets/images/9e1c47003977-1721017798342-84d8712c-ef40-43f1-8466-ec420f18db8c.png)

  
微信商户账号成功绑定后，客户在客户端使用微信在线支付功能进行线上充值，充值金额将自动转入客户余额.  

![](../../../../.gitbook/assets/images/4cc8153b5e1a-1681703205031-5cd92592-5f30-4b02-99be-d3ae16648ec8.png)
