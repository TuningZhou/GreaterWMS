# 其他费用

统计公司运营中出现的一些其它开支费用，管理公司的每一笔收支明细，帮助公司财务进行成本核算。  
【**功能入口**】（**结算—其他费用—运营开支**）

![](../../../.gitbook/assets/images/e4afad184821-1721016356779-7a3a8932-5cc8-47c8-a9bc-3dc61fd09140.png)

  
点击新建   

![](../../../.gitbook/assets/images/780dc14ed304-1721016382870-02200c70-68cf-4d17-a88d-bf5bc8e7a2c3.png)

选择发生交易的银行账户，交易类型可选择是**支出**或者**收入**，会计科目通过后方**设置**图标新增类型，录入金额后确定保存。

![](../../../.gitbook/assets/images/011118ccedd4-1721016422471-2868d33f-c094-4b97-8b1e-346a80696ccf.png)

交易创建成功后，点击审核，账户结算完成并生成相应的交易流水。

![](../../../.gitbook/assets/images/b94e1c8152ef-1721016439336-85213cd9-e323-4989-9633-f7892f2d84fd.png)
