# SKU映射

【**功能概述**】当同一产品在不同销售平台Listing的SKU不同，或者Listing SKU与仓库SKU不同时，可以通过SKU映射来进行产品SKU的匹配.

点击**新建**，选择销售平台账号

![](../../../../.gitbook/assets/images/6bf6f228f8b3-1723197551830-eca93c09-e802-4c3b-abaf-a462a75c0fab.png)

录入销售平台Listing的SKU和映射到仓库的SKU确定保存，点击增加映射项可对组合产品实现多映射

![](../../../../.gitbook/assets/images/142f42066a2b-1725259951315-4c3675fe-4ed9-4f01-950e-2e057e19697d.png)

SKU映射创建后，销售平台同步到系统的订单SKU会自动和仓库SKU进行匹配

也可以通过批量导入的方式来进行SKU映射的创建

![](../../../../.gitbook/assets/images/fabfd47d9905-1723197619206-e184f63c-2805-4df6-9cbd-54ac19e05e14.png)
