# shein

进入客户端系统授权，销售> 平台账号 > 新建

**账号类型**：shein

**销售账号**：自定义

点击**现在去授权**，跳转shein进行授权

![](../../../../../.gitbook/assets/images/9a1b51bd1a09-1726114113613-1f874ee5-3096-4cd0-b99c-e61ad286a08d.png)

![](../../../../../.gitbook/assets/images/f6336b3c8646-1726114141366-b6a21c6b-2eb1-4804-8ab2-f5ab15dc3c1a.png)
