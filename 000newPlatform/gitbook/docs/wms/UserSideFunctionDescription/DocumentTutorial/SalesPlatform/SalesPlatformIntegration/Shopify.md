# Shopify

1. 应用名称随意填写，填写后点击【创建】.

![](../../../../../.gitbook/assets/images/cc2987d7cd69-1776740043747-84b24163-cd60-4bdc-a8ab-5c6b4849f6bd.png)

2. URL-应用url填写<https://tms.dmxsmart.com/>
3. 访问权限-访问范围填写 read_assigned_fulfillment_orders,write_assigned_fulfillment_orders,read_merchant_managed_fulfillment_orders,write_merchant_managed_fulfillment_orders,read_orders,write_orders,read_third_party_fulfillment_orders,write_third_party_fulfillment_orders,read_customers

![](../../../../../.gitbook/assets/images/0e6cab2a730f-1776740071611-6c084e6c-ac4f-479e-a86d-b410a768acb6.png)

4. 填写完成后，在最下方点击【发布】
5. 版本名称无需填写，直接点击发布【发布】

![](../../../../../.gitbook/assets/images/74806b2ed927-1776740122822-4eede998-40c6-49cb-bd1c-7bc992acceb4.png)

6. 发布后，在左侧点击设置，客户端id和加密密钥填入系统。分别对应系统的Client Id 和 Client Secret。

![](../../../../../.gitbook/assets/images/dc5d650aa7f4-1776740155882-8ac4fab1-9dc7-4fbd-965a-ebcee6c8834b.png)

![](../../../../../.gitbook/assets/images/6300b5bfee70-1776739983293-9963772a-3a08-4630-a4bb-4fd0aab25830.png)

7. 回到dev dashboard，点击左侧应用名称，然后点击右方【安装应用】

![](../../../../../.gitbook/assets/images/5c6a978e6044-1776740193454-963198fc-69cf-4a22-9f21-adfe7083a100.png)

8. 在跳出的页面中，选择需要授权的店铺，再点击安装，完成授权。

![](../../../../../.gitbook/assets/images/4f29acce9f83-1776740215924-081d2521-7d85-4d90-af5e-31f5e800b8c1.png)

![](../../../../../.gitbook/assets/images/e48561221956-1776740255384-48bfb884-e826-48f6-8d47-0949bc0725ca.png)

**销售账号**：自定义，

**StoreName**： 输入店铺域名. 例如 damai123.myshopify.com

![](../../../../../.gitbook/assets/images/92de8980015c-1776740378538-f43a1ea6-3eb9-4a3b-89c9-a652dd5c6062.png)

![](../../../../../.gitbook/assets/images/602623948824-1777272190516-f8dc04d8-e579-44c9-aecc-6b39c6543075.png)

录入后保存，完成Shopify账号对接.

通过**自动同步**和**拉取订单**功能将Shopify订单同步到系统提交出库.
