# tiktokshop

进入客户端系统授权，销售> 平台账号 > 新建

**账号类型**：TikTokShop

**销售账号**：自定义

**区域**： 美国本土店铺选择美国本土，否则就选其他

**下单订单状态**： Awaiting Shipment

点击**现在去授权**，跳转tiktokshop进行授权（ 首次授权需要登录TMS.DMXSMART.COM域名进行授权 ）

![](../../../../../.gitbook/assets/images/c4d369203b66-1726114998396-c121d462-c2e8-4be1-b937-a020a50346c0.png)

![](../../../../../.gitbook/assets/images/9829bdfb810f-1730788107685-2781e250-9644-49be-a2f7-0d49bbbfa06c.png)

登录tiktokshop账号并授权

![](../../../../../.gitbook/assets/images/2373ba16c493-1726115579256-e54fd6f7-2333-4f51-8c95-05870db553be.png)
