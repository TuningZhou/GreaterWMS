# 账单记录

【功能概述】账单费用查询，账单明细导出。

![](../../../../.gitbook/assets/images/ddc0627ccc56-1723426700974-ef4b3a16-c537-427a-9112-a04b847f6fd6.png)

客户无法对账单费用进行任何编辑、修改等操作，账单由管理端创建，已生成的账单通过操作可以导出发票、账单明细等动作。

![](../../../../.gitbook/assets/images/788a4c7c645f-1723426922051-421f083b-93d2-46dc-ba2a-5d62239cfb95.png)
