# 充值记录

【功能概述】在线充值以及线下充值记录查询。点击新建创建充值记录，客户端创建的充值记录需由管理端进行审核。

![](../../../../.gitbook/assets/images/f3fd62b7162a-1723426543535-0244813a-cfea-452e-af34-e3c3b855bd90.png)

点击新建，创建充值记录，输入汇率，点击可进行汇率换算

![](../../../../.gitbook/assets/images/4c472573aafd-1724041550700-cbdb0fa3-631b-4bbf-a688-eff01bdac2cb.png)

支持币种转换汇率计算功能

![](../../../../.gitbook/assets/images/93558f97ec5f-1724041605959-8becfdf7-5913-43c0-9120-ea32e321cf85.png)

![](../../../../.gitbook/assets/images/a0951d2d33a9-1721013685827-a887d36b-99de-4526-bc33-1925d8f04d57.png)
