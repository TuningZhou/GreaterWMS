# 创建订单

【**功能概述**】仓库收货并完成上架后，产品在系统后台产生实际库存即可创建订单，做订单提交出库动作，产品没有库存或者库存数量不足的订单无法提交出库。

【**功能入口**】（**订单**—**创建订单**）

1. 地址信息编辑，选择发货仓以及运送方式，录入收件人地址信息。带红色*号为必填项。

![](../../../.gitbook/assets/images/3aff20ddc340-1722393046767-07806316-bbc5-4735-8548-b2b659850b00.png)

2. 配货信息编辑，点击**添加**，选择需要发货的产品和数量。

![](../../../.gitbook/assets/images/309fce125412-1628674092922-b53e6e52-8233-44ec-b939-fdd78e691edf.png)

当SKU数量多时可通过模糊搜索功能查找需要的SKU

![](../../../.gitbook/assets/images/4126406156ac-1629356903932-0708515d-4eb7-4756-a7fd-6f7dd81346a8.png)

3. 订单信息编辑完成后点击右上角**保存并关闭**，或点击**保存并继续**创建多个订单。

![](../../../.gitbook/assets/images/2f44b8cb84ee-1722393730522-a9d9953f-0a8d-4ecf-aaeb-fd31ac1c24e7.png)

4. 保存后的订单可以到（**订单列表**—**草稿**）里进行编辑、审核以及提交。

![](../../../.gitbook/assets/images/30ac0e9d2fb5-1722393976370-6817bffb-c818-4d27-a1c0-6adb5abaf473.png)
