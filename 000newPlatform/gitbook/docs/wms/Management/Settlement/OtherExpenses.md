# 其它费用

【**功能概述**】统计公司运营中出现的一些其它开支费用，管理公司的每一笔收支明细，帮助公司财务进行成本核算。

![](../../../.gitbook/assets/images/f29c172f3a44-1722998651701-fb819c22-b794-43b6-9562-a37e28948749.png)

点击**新建**  

![](../../../.gitbook/assets/images/67350625cb14-1722998676476-94345f03-f61e-45f7-8336-b394a4764cdc.png)

选择发生交易的银行账户，交易类型可选择是**支出**或者**收入**，会计科目通过后方**设置**图标新增类型，录入金额后确定保存。  

![](../../../.gitbook/assets/images/877a4258bd80-1662454853202-fa23fc58-60e4-4b58-ae6e-59d0c639049e.png)

交易创建成功后，点击审核，账户结算完成并生成相应的交易流水。  

![](../../../.gitbook/assets/images/dd5b2c480c07-1662455033456-8d6ee62d-f743-479b-85e6-4c34f669f286.png)

  
可在银行账户流水中查看  

![](../../../.gitbook/assets/images/2f2c2f9122e1-1722998798436-914b6b54-647f-4f4c-aa77-0587af01e2be.png)
