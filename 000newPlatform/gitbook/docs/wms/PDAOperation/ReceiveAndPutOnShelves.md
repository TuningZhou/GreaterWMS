# 接收上架

## 接收

客户货物发往海外仓前需做入仓预报，并打印箱唛标签贴在外箱上。货箱到库后仓库人员需要手持PDA设备进行仓库预报接收。  
入仓预报会在预报列表-待接收中显示。

![](../../.gitbook/assets/images/60b5c844cc46-1723090859988-44ea31cc-50ec-4822-8eb8-3647fd523477.png)

### 按箱接收

仓库人员使用 **入仓-按箱接收** 扫描货箱的入仓箱唛条形码进行接收操作

![](../../.gitbook/assets/images/65ae32fa133c-1723089416097-ad387025-8948-469e-a525-729508e013ff.png)

点击扫描标签或输入货箱编码

![](../../.gitbook/assets/images/bfe8d64ffe28-1723089430399-40ba24dc-4dc0-45d9-ad59-6a97c1df88d3.png)

  
输入接收货箱尺寸，点击保存接收，该预报单将转入已接收状态  

![](../../.gitbook/assets/images/19e7b41cd562-1723089668244-1a4b039f-c665-4e22-881c-f9e81c821815.png)

### 预报接收

使用 **入仓-预报接收** 扫描预报单编码或入仓单编码进行接收操作

![](../../.gitbook/assets/images/feaf765fe0f1-1723090004190-142f0593-c330-424d-b9af-44089471c036.png)

  
扫描后可以修改货箱的入仓时间（默认当前时间）、到仓方式、货箱装载方式和备注等，如不需要修改信息则直接点击下一步  

![](../../.gitbook/assets/images/cfaff275d8d4-1723090139630-1cad85ba-8c7a-44a5-8a84-326f2b565dc2.png)

  
核对货物信息与预报信息一致后，可以点击全部接收，或按照货物实际情况修改箱子的尺寸、重量。

填写好本次接收的货箱长宽高以及接收箱数后点击**下一步**

![](../../.gitbook/assets/images/0d010d9af863-1723090703627-9fb6984c-ed0b-4e9e-b6a3-439ad967b75a.png)

  
接收时可以选择上传接收的货箱清单等数据，最后点击保存即完成该批次的接收操作。  
该预报单转入已接收状态。  

![](../../.gitbook/assets/images/06d3a89f6501-1723091184722-837d21b2-7e0e-48b6-8373-93d76fb0e4bb.png)

### 接收记录

仓库人员可在 **入仓-接收记录** 中查看接收货箱详情或取消某批次的接收操作

![](../../.gitbook/assets/images/efc9a0c937d3-1723091351216-aa01e189-ae12-49e2-9a6a-e94b13f511d6.png)

  
点击搜索查找接收记录，取消某批次的接收或查看入仓预报详情  

![](../../.gitbook/assets/images/add379abff71-1723091570889-61a178ac-8cce-41ee-ba4e-892718959b57.png)

## 上架

### 产品上架

接收完成后，使用 **入仓-产品上架** 扫描本次要处理上架的货箱箱唛，进行产品上架

![](../../.gitbook/assets/images/5b30ec7440a2-1723097557381-2552d990-9f2e-465e-923b-38ee186015f2.png)

  
填写处理数量或选择所有货箱，点击下一步  

![](../../.gitbook/assets/images/69166b0a7408-1723097857987-f416fd5d-7fa5-4b86-bf47-91b56340cf58.png)

扫描产品sku标签以及库位标签，填写本次的上架的产品数，如果该sku之前有在仓库有上架过则将自动填充长宽高重量等数据。

![](../../.gitbook/assets/images/dfdea3ed70b4-1723098510377-44bf0871-83b7-4661-8bcf-e59f6a2288bf.png)

  
点击确定 确认上架这一款sku，填写完成后点击下一步  

![](../../.gitbook/assets/images/50e674e1fc40-1723098394547-906fc8a0-bea4-483a-a162-06109350af40.png)

  
查看本次操作上架清单和汇总，确认无误后点击保存完成本轮上架操作  

![](../../.gitbook/assets/images/ae3e7cdc1774-1723098859003-7d7a99c8-9b99-4e17-8d6c-61f6d749d35f.png)

### 处理记录

可在 **入仓-处理记录** 中查看货物上架、暂存和转运处理记录

![](../../.gitbook/assets/images/a58e510ac385-1723099145643-24194d50-44d0-417c-9e6b-5aae8787edc6.png)

  
点击搜索查找处理记录，对于未完成的上架操作可点击取消该次上架  

![](../../.gitbook/assets/images/9763ead3eef3-1723099256554-ea550f4b-3439-47ff-ade8-5a68e4a1bc70.png)
